# Example scripts

| File | What it's for |
|---|---|
| `01-practice.R` | The practice from [Step 4](../README.md#step-4--practise-on-your-laptop). Safe: everything stays on your laptop. |
| `connect.R` | Connects to the team's board and adds `save_version()` and `history()` ([Step 5](../README.md#step-5--connect-to-the-teams-board)). Fill in the bucket once. |
| `.Rprofile` | Runs `connect.R` automatically whenever R starts in your project folder ([Step 5](../README.md#step-5--connect-to-the-teams-board)). |
| `save-new-version.R` | Saves a new version of a file, with your name as the author ([Step 6](../README.md#step-6--every-day-the-same-four-things)). Change three lines and run it. |

Copy `connect.R`, `.Rprofile` and `save-new-version.R` into your project folder, for example `C:\projects\my-data`.
